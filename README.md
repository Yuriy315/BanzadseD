# Expense Tracker 💰

**Автор:** [Давид Банцадзе]
**Язык:** Python 3.13

## Описание программы

Expense Tracker — это простое графическое приложение для учёта личных расходов.
Позволяет добавлять расходы с указанием суммы (поддерживаются десятичные дроби), категории и даты.
Ключевые функции: подсчёт общей суммы за выбранный период и фильтрация по категории.
Данные сохраняются в файл `expenses.json`.
Проект управляется с помощью системы контроля версий **Git**.

## Инструкция по запуску

> Для работы программы требуется библиотека `tkcalendar`. Установите её перед запуском.
>
> ```bash
> pip install tkcalendar
> ```
>
> Или установите все зависимости из файла:
>
> ```bash
> pip install -r requirements.txt
> ```
>
> Затем запустите приложение:
>
> ```bash
> python expense_tracker.py
> ```

## Как использовать приложение

1.  **Добавление расхода:**
    *   Введите сумму (например: `599.99` или `1 250`).
    *   Выберите категорию из списка.
    *   Выберите дату в календаре.
    *   Нажмите кнопку «Добавить расход».
    *   Поля проверяются: сумма должна быть положительным числом.
2.  **Подсчёт суммы за период:**
    *   Выберите начальную дату в поле «Период».
    *   Выберите конечную дату в поле «по».
    *   Нажмите кнопку «Сумма за период». Результат появится во всплывающем окне.
3.  **Фильтрация:**
    *   Выберите категорию в выпадающем списке «Категория».
    *   Нажмите кнопку «Фильтр по категории». В таблице отобразятся только расходы из выбранной категории.
4.  **Сохранение:**
    Данные сохраняются автоматически при добавлении нового расхода.
5.  **Загрузка:**
    При запуске программы список расходов загружается из файла `expenses.json`.
