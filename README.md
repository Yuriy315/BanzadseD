# Book Tracker 📚

**Автор:** [Давид Банцадзе]
**Язык:** Python 3.13

## Описание программы

Book Tracker — это простое графическое приложение для учёта прочитанных книг.
Позволяет добавлять книги в список с указанием названия, автора и жанра.
Реализована фильтрация по жанру и количеству страниц.
Все данные сохраняются в файл `books.json` в формате JSON.
Проект управляется с помощью системы контроля версий **Git**.

## Инструкция по запуску

1. Установите Python 3.13 (версия 3.7 и выше).
2. Клонируйте этот репозиторий или скачайте ZIP-архив.
3. Откройте терминал в папке проекта и установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   python book_tracker.py
   ```
5. Пользуйтесь!

## Как использовать приложение

1. **Добавление книги:**
   Заполните все поля («Название», «Автор», «Жанр», «Страниц») и нажмите кнопку «Добавить книгу».
   Поля проверяются: все должны быть заполнены; «Страниц» — только целое число больше 0.
2. **Фильтрация:**
   Введите жанр (например: *фантастика*) в поле «Жанр» и/или минимальное количество страниц в поле «Мин. страниц».
   Нажмите «Применить фильтр».
3. **Сохранение:**
   Данные сохраняются автоматически при добавлении новой книги.
4. **Загрузка:**
   При запуске программы список книг загружается из файла `books.json`.

## Технологии
